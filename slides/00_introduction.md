# Bonnes pratiques IA & Développement

## Guide pour une utilisation professionnelle, critique et responsable

---

# Pourquoi ce guide ?

L'IA générative est adoptée massivement par les développeurs.

Mais entre **utiliser** l'IA et **bien** l'utiliser, il y a un fossé.

Ce guide comble ce fossé.

---

# Le problème

| Risque                              | Conséquence               |
| ----------------------------------- | ------------------------- |
| Accepter du code sans le comprendre | Dette technique invisible |
| Coller des données sensibles        | Fuite de données          |
| Faire confiance aveugle             | Bugs en production        |
| Déléguer la réflexion               | Solutions inadaptées      |

**Ces risques se produisent quotidiennement.**

---

# Le bénéfice d'une utilisation maîtrisée

- **Productivité** : automatisation des tâches répétitives
- **Qualité** : tests, détection d'anomalies, review augmentée
- **Apprentissage** : montée en compétence accélérée
- **Concentration** : moins de charge cognitive sur le boilerplate

---

# La condition

> L'esprit critique reste activé en permanence.

---

# Le principe fondateur

> **L'IA est un amplificateur.**
> Elle amplifie la compétence du développeur compétent.
> Elle amplifie aussi l'incompétence.
> Le facteur déterminant, c'est **vous**.
